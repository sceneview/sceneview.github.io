PlacementGuide

class PlacementGuide

What an automatic placement shows around the object right now: one rule for every app, so a viewer, a furniture app and a measuring app teach the same gestures (#5209).

The surfaces say where the object can go, so they show while it is looking for one and while it moves, then fade: a placed object stands on its contact shadow, and nothing else moves on screen. Scene Viewer and IKEA Place show their dots the same way; AR Quick Look draws none.

AutoPlacementScene reads it for the plane renderer and the selection ring. Read it from AutoPlacementState.guide for marks of your own, such as DimensionMarks.
