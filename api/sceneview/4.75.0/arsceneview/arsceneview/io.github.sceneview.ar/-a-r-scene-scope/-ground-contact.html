GroundContact

@Composable
fun GroundContact(center: () -> Position?, radius: Float, normal: Direction = Direction(y = 1f))

Registers a contact disc that keeps surface depth noise from cutting a placed object's contact shadow, placement ring and feet. Use alongside custom placement in ARSceneView; AutoPlacementModel already registers its own contact.

center is read on the main thread each rendered frame, after nodes have moved. Return null while the object is not placed or no longer valid. The contact is removed when this composable leaves the composition. This draws nothing and does not enable depth occlusion: enable it on the camera stream (or with SceneUnderstanding) and enable session depth.

All coordinates are in world space, including for nodes parented to an anchor. Put the centre on the supporting surface, not at the model's bounding-box centre. For a node whose origin is on the floor:

GroundContact(center = { node.takeUnless { it.isDestroyed }?.worldPosition }, radius = ringRadius)

Only the valid contact nearest the camera is used. Within its disc the existing occlusion material tolerates depth noise up to 10 cm nearer than the surface, fading out beyond the radius; real geometry sufficiently in front still occludes. Custom camera materials must support the groundContact and groundNormal parameters to use this band.

Parameters

center

Provider of the disc centre in world metres, or null to suspend it.

radius

Disc radius in world metres, covering the contact shadow and ring.

normal

World-space surface normal, normalized internally; defaults to a floor's +Y. Non-finite values, a non-positive radius or a zero-length normal disable this contact.
