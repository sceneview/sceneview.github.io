CinematicCameraManipulator

class CinematicCameraManipulator(val animator: CameraAnimator, val inner: CameraGestureDetector.CameraManipulator, handoverSeconds: Float = HANDOVER_SECONDS) : CameraGestureDetector.CameraManipulator

Cinematic moves over a gesture camera, in one cameraManipulator.

While the animator plays, the camera is its CameraAnimator.shot; the first touch interrupts the move and the inner manipulator takes over, without a cut:

  • an inner that is a CameraShotSink is handed the shot and the velocity, and carries on from there — the demo app's orbit camera does this;

  • any other manipulator (the default orbit manipulator included) keeps its own pose, so the camera glides from the move's last shot onto that pose over handoverSeconds, following it as the finger drags, the same glide a cameraManipulator swap gets.

A move that reaches its end hands over the same way, at zero velocity: a sink is given the last shot and the camera stays on it; any other manipulator is glided onto from it. A CameraAnimator.snapTo is handed over too. Nothing cuts back to the gesture camera's old pose.

Under FrameRatePolicy.OnDemand a parked scene wakes for a CameraAnimator.play, CameraAnimator.flyTo or CameraAnimator.snapTo made from anywhere — a button, a LaunchedEffect — and keeps drawing for as long as isFrameActive says.

getTransform() is called once per frame by the render loop and only then, as the CameraGestureDetector.CameraManipulator contract requires; this calls inner's at most once per frame too.

val animator = remember { CameraAnimator(initial = home) }
SceneView(cameraManipulator = rememberCinematicCameraManipulator(animator)) { … }
LaunchedEffect(model) { animator.play(CameraPath.reveal(home)) }
