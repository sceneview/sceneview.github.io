CameraPath

class CameraPath(keyframes: List<CameraKeyframe>, val easing: (Float) -> Float = CameraEasing.Expressive, val shortestArc: Boolean = true, val loop: Boolean = false)

A camera move through keyframes: the camera passes each CameraKeyframe.shot at its time and flows between them on a cubic spline (Catmull-Rom over the orbit parameters), so its speed is continuous across a keyframe — no kink, no change of pace the eye can catch.

Two keyframes make a plain move. With one keyframe, or none, the path holds that shot.

  • easing shapes the time of each segment between two keyframes (0..1 of that segment), so every keyframe is reached at exactly its declared CameraKeyframe.seconds. CameraEasing.Expressive lands a reveal softly and, through several keyframes, settles on each one before leaving it (its speed is zero at both ends of a segment, so still continuous); CameraEasing.Linear flows through the keyframes without slowing — what a looping tour wants.

  • shortestArc unwraps each keyframe's azimuth the short way round from the one before. Off, the azimuths are taken as given: a tour spells its turn as azimuthDegrees + 360f.

  • loop wraps time past the end back to the start; the spline then closes, so the last keyframe should equal the first (as tour does) for the loop to be seamless.

Ready-made paths: reveal, the entrance shot of a scan or a model, and tour, a slow lap for a video or a share. Feed either to CameraAnimator, or sample shotAt yourself.

shotAt

fun shotAt(seconds: Float): CameraShot

The shot seconds into the path — counted from the first keyframe, the same clock as isFinishedAt and CameraAnimator. Past the end a path holds its last shot; a loop wraps, and its azimuth keeps counting (lap two of a tour reads home + 720°), so the camera's velocity is the same across the seam as anywhere else — nothing for a touch to catch.
