CameraPose

data class CameraPose(val position: Position = Position(), val quaternion: Quaternion = Quaternion())

Where a camera stands and which way it faces, in world space: a position and a unit quaternion.

The rotation follows the Filament camera convention: an identity quaternion looks down -Z with +Y up, so forward is -Z rotated by quaternion.

CameraShot describes a camera by the subject it orbits. A pose describes it by where it is, which is what a keyframed move needs: a travelling or a dolly is a straight line through space, not an arc around a subject. CameraPosePath interpolates poses; CameraNode.applyPose writes one to a camera.
