PlaneNode

open class PlaneNode : GeometryNode

A node that renders a procedural flat quad (plane) geometry.

The plane has the given size (width x height), is centred at center, and faces the specified normal direction. UV coordinates are scaled by the optional uvScale.

Use the composable SceneScope.PlaneNode(...) for declarative usage inside a SceneView { } block, or instantiate this class directly for imperative code.
