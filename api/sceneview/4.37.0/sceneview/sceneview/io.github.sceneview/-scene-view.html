SceneView

A Filament 3D scene declared as Compose UI.

SceneView is a @Composable that embeds a Filament viewport. Its trailing content block is a SceneScope DSL where every node — models, lights, cameras, geometry, Compose UI — is itself a composable function. Nodes enter the scene on first composition and are automatically destroyed when they leave, with no manual lifecycle management required.

3D content is reactive: pass Compose state into node parameters and the scene updates on the next frame exactly like any other composable.

Minimal usage

SceneView(modifier = Modifier.fillMaxSize()) {
    rememberModelInstance(modelLoader, "models/damaged_helmet.glb")?.let { instance ->
        ModelNode(modelInstance = instance, scaleToUnits = 0.5f)
    }
}

Parameters

modifier

Modifier for the underlying surface.

surfaceType

SurfaceType.Surface (SurfaceView, renders behind Compose layers, best GPU performance) or SurfaceType.TextureSurface (TextureView, renders inline, supports alpha blending). Default: SurfaceType.Surface.

engine

Shared Filament Engine. Use rememberEngine.

modelLoader

Loader for glTF/GLB models. Use rememberModelLoader.

materialLoader

Loader for Filament material templates. Use rememberMaterialLoader.

environmentLoader

Loader for HDR/KTX environments. Use rememberEnvironmentLoader.

view

Filament View (one per window). Use rememberView.

isOpaque

Whether the render target is opaque. Default true.

isRendering

Whether the internal frame loop runs. Default true. Pass false on a completely idle scene to park the loop and stop drawing; a new or resized surface still gets one frame. See the parameter's own KDoc for how to drive it — the dirty signal must be Compose state.

renderQuality

One-line preset applied to view (RenderQuality.Default, RenderQuality.Cinematic, or RenderQuality.Performance).

autoCenterContent

When true (default), the library translates all DSL content nodes once — on the first frame their union bounding box is non-empty — so the content centroid lands on the world origin and renders centred in the viewport without each node needing ModelNode(centerOrigin = …). It lands on the origin, not on the manipulator's targetPosition; the two coincide only for the default target, which is why the camera-to-subject distance is |orbitHomePosition| — see rememberCameraManipulator. Lights / camera are passed as separate parameters, never DSL children, so they are unaffected. Mirrors the iOS autoCenterContent feature (#1026). Pass false for scenes with intentional off-centre placement — authored world positions then survive.

autoFitContent

When true, the library moves cameraNode so the DSL content fills the viewport — regardless of the model's intrinsic glTF size, with no per-model scaleToUnits tuning (#1439). The pass re-frames whenever an async model grows the content's union bounds and latches once that union has settled, then leaves the camera alone so subsequent user zoom / pan is never fought. Default false so callers that position cameraNode explicitly keep full control; opt in for model-viewer style scenes.

framingPadding

Extra air the autoFitContent pass leaves around the content, as a fraction of the fit distance — 0.15 (the default, DEFAULT_FRAMING_PADDING) adds 15% of distance, 0 frames the bounds exactly tangent. Clamped to >= 0. Per-scene counterpart of CameraNode.frameToContent(padding = …) (#2946). Not the iOS framingMargin multiplier: margin == 1 + padding, so iOS 1.15 is 0.15 here. No effect when autoFitContent is false.

renderer

Filament Renderer. Use rememberRenderer.

scene

Filament Scene graph, shareable across views. Use rememberScene.

environment

IBL + skybox environment. Use rememberEnvironment.

mainLightNode

Primary directional light (required for shadows).

fillLightNode

Secondary fill light (softer ambient — opposite-side directional at ~30% main intensity). Use rememberFillLightNode or pass null for a single-light setup.

cameraNode

Active rendering camera. Use rememberCameraNode.

collisionSystem

Hit-testing and collision system. Use rememberCollisionSystem.

cameraManipulator

Orbit/pan/zoom camera controller. Use rememberCameraManipulator.

viewNodeWindowManager

Off-screen window manager required for SceneScope.ViewNode.

surfaceMirrorer

Mirrors every rendered frame to additional android.view.Surfaces — attach a MediaRecorder input surface for clean in-app video recording (no MediaProjection). Use rememberSurfaceMirrorer.

onGestureListener

Gesture callbacks — tap, double-tap, drag, pinch, etc.

onTouchEvent

Raw touch event callback with optional hit-test result.

activity

Host ComponentActivity (auto-resolved from LocalContext).

lifecycle

Lifecycle that drives rendering resume/pause.

onFrame

Called once per presented frame, right after it reached the surface. A tick on which Renderer.beginFrame refused the frame — which is most of them while the GPU warms a heavy material up — is not a rendered frame and does not call this back (#3444), so "I was called" is a sound signal that there are pixels on screen. Use it to drop a loading cover or drive per-frame logic; it does not fire while isRendering is false.
