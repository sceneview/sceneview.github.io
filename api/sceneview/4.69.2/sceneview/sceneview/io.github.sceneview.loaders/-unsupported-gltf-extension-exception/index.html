UnsupportedGltfExtensionException

class UnsupportedGltfExtensionException(val extensions: List<String>) : IllegalArgumentException

A glTF or GLB model lists, in extensionsRequired, an extension the bundled Filament gltfio cannot load (extensions, in file order). The glTF specification says a loader must refuse such a file; gltfio does not check the list and loads it anyway, without what the extension carries (an EXT_texture_avif model renders untextured).

Detected before any Filament call, so nothing was created and nothing needs destroying. Only ModelLoader.awaitModelInstance refuses such a model, by throwing this, and io.github.sceneview.rememberModelLoadState hands it over as io.github.sceneview.ModelLoadState.Failed. Every other load (create*, load*, load*Async, rememberModelInstance) logs the unsupported extensions and loads the model as it always did.

What gltfio supports: ModelLoader.SUPPORTED_GLTF_EXTENSIONS. A generation or optimisation pipeline can usually export without the offending extension (PNG/JPEG or KTX2 textures instead of AVIF, EXT_meshopt_compression instead of KHR_meshopt_compression).
