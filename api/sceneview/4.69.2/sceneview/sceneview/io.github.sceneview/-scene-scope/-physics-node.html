PhysicsNode

@Composable
fun PhysicsNode(node: Node, restitution: Float = 0.6f, linearVelocity: Position = Position(0f, 0f, 0f), floorY: Float = 0.0f, radius: Float = 0.0f)

Attaches a simple rigid-body physics simulation to a node.

Applies gravity (-9.8 m/s²), floor collision, and bouncing via Euler integration. The target node must already exist in the scene graph — this composable drives its position each frame.

SceneView {
    val mat = remember(materialLoader) { materialLoader.createColorInstance(Color.Red) }
    SphereNode(radius = 0.15f, materialInstance = mat, position = Position(0f, 3f, -2f)) {
        // This sphere will fall and bounce:
    }
    // Or use a remembered node reference:
    val sphereNode = remember(engine) { SphereNode(engine, radius = 0.15f) }
    PhysicsNode(
        node = sphereNode,
        restitution = 0.7f,
        linearVelocity = Position(x = 0.5f, y = 2f, z = 0f),
        radius = 0.15f
    )
}

Parameters

node

The Node whose position is driven by the simulation. Must be in scene.

restitution

Bounciness in 0, 1. 0 = inelastic, 1 = perfectly elastic.

linearVelocity

Initial velocity in m/s (world space).

floorY

World Y coordinate of the floor plane. Default 0.

radius

Collision radius in metres (offsets contact point for sphere surface).
