XrHandSkeleton

object XrHandSkeleton

Pure-logic helpers describing the hand skeleton: the bone topology and the small amount of vector math XrHandNode needs to lay joints / bones out.

Stateless object — everything here is referentially transparent and trivially unit-testable.
