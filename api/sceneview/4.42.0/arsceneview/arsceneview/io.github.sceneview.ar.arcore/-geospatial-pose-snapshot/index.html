GeospatialPoseSnapshot

data class GeospatialPoseSnapshot(val latitude: Double, val longitude: Double, val altitude: Double, val heading: Double, val horizontalAccuracy: Double, val verticalAccuracy: Double, val orientationYawAccuracy: Double)

Snapshot of every field a GeospatialPose exposes — addresses the audit finding (#1769) that the existing GeospatialPose.transform extension projects only 3 of 7 fields (lat/lng/altitude) into a SceneView io.github.sceneview.math.Transform, dropping the four accuracy / heading fields apps need to gate UI on signal quality.

Every field is in WGS84 conventions:
