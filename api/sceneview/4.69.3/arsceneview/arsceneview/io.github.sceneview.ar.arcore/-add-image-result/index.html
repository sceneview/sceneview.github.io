AddImageResult

sealed class AddImageResult

Outcome of RuntimeAugmentedImageDatabase.addImage.

Modelled as a sealed hierarchy so callers can when-match exhaustively and give the user a specific message — the most common failure (LowQuality) is recoverable by retaking the photo, so it must be distinguishable from a hard error.
