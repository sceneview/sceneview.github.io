ModelSnapshotOptions

data class ModelSnapshotOptions(val yawDegrees: Float = DEFAULT_YAW_DEGREES, val pitchDegrees: Float = DEFAULT_PITCH_DEGREES, val focalLength: Float = DEFAULT_FOCAL_LENGTH, val padding: Float = DEFAULT_PADDING)

How ModelSnapshot frames a model.

The default is a three-quarter view from slightly above, the angle a product shot uses: the camera turns yawDegrees from the model's front (glTF +Z) toward its right, and looks down pitchDegrees. The model is then framed whole, as tight as padding allows, and centred on its silhouette.

Parameters

yawDegrees

rotation of the camera around the model's vertical axis, from its front (+Z) toward its right (+X). 0 is a straight front view, 90 its right side, 180 its back.

pitchDegrees

how far above the model's horizontal plane the camera sits, in degrees, strictly between -90 and 90. Negative values look up at the model.

focalLength

lens focal length in millimetres (Filament's 24 mm sensor height). The default 40 mm is the demo showroom's lens: a natural perspective, without a wide-angle bulge.

padding

fraction of the image's width and height left empty on each side, in [0, 0.5).
