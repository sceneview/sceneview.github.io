awaitModelInstance

suspend fun awaitModelInstance(fileLocation: String, resourceResolver: (resourceFileName: String) -> String = { getFolderPath(fileLocation, it) }, onProgress: (ModelLoadProgress) -> Unit = {}): ModelInstance

Loads a single ModelInstance and returns once its textures are final, reporting progress along the way — for the large, texture-heavy models generation services produce (tens of MB, 4K textures), where a load takes long enough to show a progress bar.

The file is read and converted off the main thread, and the textures decode on Filament's job system; only Filament's own calls (creating the asset, beginning the load, finalising each texture) run on the main thread. While it waits it finalises textures itself, so it also completes in a scene that renders no frame meanwhile. That wait polls every 16 ms on the main thread, suspending in between: each poll is one asyncUpdateLoad (it uploads the textures decoded since the last one), so the thread stays free for frames and input. Several calls can run at once on the same loader: each follows, and waits for, its own model's textures. Beginning a second load while a first one still decodes blocks the main thread until the first one's texture decoders have finished: that is gltfio's asyncBeginLoad, which drains the previous load's decoders before it queues new ones (the same holds for loadModelInstance and every other async load on this loader).

A texture that cannot be read (missing file, failed download) is logged and skipped: the model loads without it. As a last resort, textures that make no progress for 10 seconds stop the wait: the instance is returned with what is loaded, a texture possibly still decoding, and the stall is logged, rather than failing a model whose geometry is there.

A model that requires an extension gltfio cannot load is refused here, with an UnsupportedGltfExtensionException; every other load on this class logs it and loads the model anyway.

Return

the instance, its textures finalised, or after a 10 s stall possibly not all of them (logged).

Parameters

onProgress

called on the main thread, with a ModelLoadProgress whose fraction never goes back and that never repeats a step, ending with Textures at 1 (below 1 only after such a stall).

Throws

UnsupportedGltfExtensionException

if the model requires an extension gltfio cannot load (see SUPPORTED_GLTF_EXTENSIONS), before anything is created.

IllegalArgumentException

when the file cannot be read or parsed (the reason is logged), or one of its external buffers is missing; or when the glTF is one Filament's release build would crash on (see createModel): the message then names each reason.

IllegalStateException

if the model was destroyed meanwhile (clear, destroy).

Cancelling the call destroys the model, unless it had already returned.
