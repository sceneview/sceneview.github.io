Former name of PlaneVisualizer.

The dots renderer became the only plane renderer in 4.57.0 (#4307) and its per-plane visualizer took the name PlaneVisualizer. This class stays so that code compiled against an earlier 4.x keeps linking: it forwards every member to a PlaneVisualizer.
