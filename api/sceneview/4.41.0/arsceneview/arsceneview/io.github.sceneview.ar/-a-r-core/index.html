ARCore

class ARCore(val onSessionCreated: (session: Session) -> Unit, val onSessionResumed: (session: Session) -> Unit, val onSessionPaused: (session: Session) -> Unit, val onArSessionFailed: (Exception) -> Unit, val onSessionConfigChanged: (session: Session, config: Config) -> Unit)

Manages an ARCore Session lifecycle.

Before starting a session this class checks camera permission and ARCore availability through an ARPermissionHandler, which decouples the permission logic from android.app.Activity and makes the class testable with a mock handler.
