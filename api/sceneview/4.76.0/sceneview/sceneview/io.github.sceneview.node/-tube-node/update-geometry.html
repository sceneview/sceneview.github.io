updateGeometry

fun updateGeometry(points: List<Position> = geometry.points, radius: Float = geometry.radius, radialSegments: Int = geometry.radialSegments, closed: Boolean = geometry.closed, capStyle: Tube.CapStyle = geometry.capStyle, radii: List<Float>? = geometry.radii, capacity: Int = 0)

Re-sweeps the tube and re-uploads it. Cheap enough to call every frame while the point count stays within capacity — see Tube.update for what is and is not reallocated. radii is one radius per point or null for radius; capStyle is ignored when closed.
