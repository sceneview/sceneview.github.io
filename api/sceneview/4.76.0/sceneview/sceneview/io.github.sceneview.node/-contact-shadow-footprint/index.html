ContactShadowFootprint

class ContactShadowFootprint(val halfU: Float, val halfV: Float, val fade: Float, val cornerRadius: Float = 0.0f)

A rounded-rectangle shape for a ContactShadowNode, set through ContactShadowNode.footprint in place of its context's ellipse.

The pool is the node's full ContactShadowNode.intensity inside the rectangle and fades to nothing across fade beyond its outline. The fade is the same width on every side: a 2.2 m sofa gets the same band on its short sides as on its long ones, and the rectangle's corners are covered, which an ellipse fitted to the same footprint leaves bare. Set the rectangle to the object's footprint: the object hides the inside, and the band around it is the shadow a viewer sees. A cornerRadius up to the smaller half-extent rounds it towards a disc, for objects whose footprint is not a box.

All four values are in the node's own units — metres at scale 1 — so they scale with the node like its size. The rectangle is centred on the quad (the context's centre offset does not apply) and its half-extents run along the quad's u and v axes (see ContactShadowNode's UV table): X and Z for a floor quad, X and Y for a wall quad. u always runs along X, so there is no YZ quad: a size with x = 0 builds a degenerate plane. Make the quad at least 2 × (half-extent + fade) on each axis, or the band is cut at its border.
