ARPermissionHandler

interface ARPermissionHandler

Abstracts camera permission and ARCore availability checks away from ComponentActivity.

By depending on this interface rather than a concrete activity, ARCore becomes testable with a simple mock implementation that returns predetermined permission and availability values.

See also

ActivityARPermissionHandler

for the production implementation backed by an activity.
