rememberMaterialLoader

@Composable
fun rememberMaterialLoader(engine: Engine, context: Context = LocalContext.current, creator: () -> MaterialLoader = { engine.createMaterialLoader(context) }): MaterialLoader

Creates and remembers a MaterialLoader for building Filament material instances.

MaterialLoader holds a set of compiled material templates (.filamat files bundled as assets) and provides factory methods for creating MaterialInstances — e.g. createColorInstance(color, metallic, roughness) for a quick PBR material.

The loader is required by geometry nodes (CubeNode, SphereNode, etc.) and ImageNode.

Parameters

engine

The Filament Engine that owns the material instances.

context

Android context used to open bundled material assets. Defaults to LocalContext.

creator

Factory for the loader.
