DetectorImageMapping

class DetectorImageMapping(val imageSize: CameraImageSize, val inputRotationDegrees: Int)

Maps a detector's output pixels back to the camera CPU image it was fed.

Vision APIs take a clockwise input rotation, and some (ML Kit) report their results in the rotated image. ARCore's camera intrinsics (Camera.getImageIntrinsics()) describe the unrotated CPU image. detectorPixelToImagePixel undoes the rotation, which gives the pixel to cast a world ray through with those intrinsics: a ray built from the camera pose and intrinsics captured with the image can be hit-tested against any later frame (Frame.hitTest(origin, originOffset, direction, directionOffset)), however far the phone moved during detection.

Pure Kotlin, no ARCore state: safe to keep while an asynchronous detector runs.

Parameters

imageSize

dimensions of the unrotated CPU image the detector is fed.

inputRotationDegrees

clockwise rotation passed to the vision API: 0, 90, 180, or 270.
