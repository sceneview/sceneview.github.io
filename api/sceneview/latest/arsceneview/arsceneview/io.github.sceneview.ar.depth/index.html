class MlDepthSession(estimator: MonocularDepthEstimator, targetHz: Float = 5.0f, context: Context? = null) : Closeable

Monocular depth for devices without ARCore's Depth API: runs a MonocularDepthEstimator on the CPU camera image and scales its output to metres against ARCore's own plane hits and feature points, then publishes an ArDepthFrame with ArDepthFrame.Source.Ml.
