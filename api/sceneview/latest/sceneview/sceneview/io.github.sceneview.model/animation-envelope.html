fun Model.animationEnvelope(clip: Int = 0, samples: Int = 24): AnimationEnvelope

Estimates a skinned clip's occupied volume without an Animator or another native instance.

ModelLoader retains only node transforms and animation accessor arrays before releasing the source buffers. Sampling is lazy, pure Kotlin, safe on a worker thread after loading, and cached per model, clip and sample count (the most recent eight requests). samples is clamped to 2–120; samples are evenly spaced from zero through the clip's last key, endpoints included. Preparation is bounded to 4 MiB of keyframe floats, 4096 source nodes and 256 clips; models exceeding those limits fall back. The bundled Fox retains 43,532 bytes of primitive arrays; on a macOS/JDK 21 JVM, median preparation was 0.45 ms and sampling 24 poses 0.35–0.57 ms (2026-11-13, warm process, excluding the existing JSON parse and object headers; not an Android benchmark).

Each pose encloses its joints plus the rest mesh's overhang beyond the rest joint extent on each of the six faces. This flesh-margin heuristic is not vertex skinning: it does not prove containment of moving flesh, morph targets, animated rigid attachments or unsampled extrema. LINEAR rotations use shortest-path slerp; STEP and CUBICSPLINE follow glTF interpolation.

No skin, no clip, an unknown clip, unsupported animation data (sparse, meshopt or embedded data-URI accessors), or a parse/sample failure returns only restPoseBoundingBox. Models made outside ModelLoader also fall back; that case reads Filament's box and requires the main thread. No animation envelope or fitting mode is selected automatically.
