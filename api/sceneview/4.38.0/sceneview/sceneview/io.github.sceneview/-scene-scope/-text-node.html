TextNode

@Composable
fun TextNode(text: String, fontSize: Float = 48.0f, textColor: Int = android.graphics.Color.WHITE, backgroundColor: Int = 0xCC000000.toInt(), typeface: Typeface = android.graphics.Typeface.DEFAULT_BOLD, widthMeters: Float = 0.6f, heightMeters: Float = 0.2f, position: Position = Position(x = 0f), scale: Scale = Scale(1f), cameraPositionProvider: () -> Position? = null, apply: TextNode.() -> Unit = {}, content: @Composable NodeScope.() -> Unit? = null)

A 3D text-label node that always faces the camera.

Text is rendered to an Android android.graphics.Bitmap via android.graphics.Canvas and displayed on a flat quad that rotates toward the camera each frame.

Parameters

text

The string to display.

fontSize

Font size in pixels used when rendering the bitmap (default 48).

textColor

ARGB text colour (default opaque white).

backgroundColor

ARGB background fill colour (default semi-transparent black).

widthMeters

Quad width in meters (default 0.6).

heightMeters

Quad height in meters (default 0.2).

position

Local position.

cameraPositionProvider

Lambda returning the camera world position every frame.

apply

Additional configuration on the TextNodeImpl.

content

Optional child nodes.
