Cone

class Cone : Geometry

A cone Geometry with a circular base and an apex, generated with smooth side normals and a flat base cap, suitable for use as a renderable mesh.

Instances are immutable once built; create one with the Builder and mutate it afterwards through update. All Filament buffer operations run synchronously and must be called on the main thread.
