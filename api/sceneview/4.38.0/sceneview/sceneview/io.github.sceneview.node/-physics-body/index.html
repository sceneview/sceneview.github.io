PhysicsBody

class PhysicsBody(val node: Node, val restitution: Float = 0.6f, val floorY: Float = 0.0f, val radius: Float = 0.0f, initialVelocity: Position = Position(0f, 0f, 0f), var floorProvider: FloorProvider? = null, gravity: Position = Position(0f, GRAVITY, 0f))

Rigid-body physics state attached to a Node.

Uses a simple Euler integration step executed every frame via the node's Node.onFrame callback. There are no external library dependencies — gravity and floor collision are handled with pure Kotlin arithmetic.

Physics coordinate system matches SceneView / Filament: +Y is up, gravity pulls in the -Y direction.

Parameters

node

The node whose Node.position is driven by the simulation.

restitution

Coefficient of restitution in 0, 1. 0 = fully inelastic, 1 = perfectly elastic. Applied on each floor bounce.

floorY

World-space Y coordinate of the floor plane used when floorProvider is null or returns null for this body. Default 0.0 (scene origin).

radius

Collision radius of the object in meters. Used to offset the floor contact point so the surface of the sphere sits on the floor, not its centre.

initialVelocity

Initial linear velocity in m/s (world space).

floorProvider

Optional dynamic floor source — typically an io.github.sceneview.ar.physics.DepthCollider (#1713) so the body bounces off the real floor / table / wall instead of a static plane. When null or when the provider returns null at the body's current XZ, the simulation falls back to the static floorY plane.

gravity

Gravitational acceleration vector in m/s², expressed in the same space as Node.position — i.e. the parent node's frame. Defaults to (0, GRAVITY, 0). Tilting this vector is how a body rolls down a sloped tray without the floor plane itself moving in the simulation: rotate the tray's pivot node for the visuals, and give the body the same gravity rotated by the pivot's inverse rotation (#3621).
