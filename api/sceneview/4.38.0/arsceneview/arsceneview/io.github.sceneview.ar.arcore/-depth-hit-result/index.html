DepthHitResult

data class DepthHitResult(val position: Position, val normal: Direction, val distance: Float)

Result of a depth-based hit test — a real-world point and the orientation of the surface it sits on, sampled from the ARCore depth image rather than from a detected com.google.ar.core.Plane.

Unlike Frame.hitTest, a depth hit test resolves a point on any real-world geometry the depth camera can see — a sofa, a slope, a cluttered desk — without waiting for ARCore to grow a plane there, and it carries a real surface normal.
