ARFogConfig

data class ARFogConfig(val density: Float = 0.05f, val start: Float = 0.0f, val end: Float = 30.0f, val color: Color = Color(0xFFCCDDFF), val enabled: Boolean = true)

Environment-aware AR fog configuration (issue #1717).

Applied to the AR camera passthrough via the depth-aware ARCameraStream material, fading distant real-world surfaces into a coloured haze using the ARCore depth image. Parameter names and ranges mirror the virtual io.github.sceneview.node.FogNode so the same numbers fog both real and virtual content consistently.

Inspired by ARCore Depth Lab's AR Fog sample.

Parameters

density

Fog density coefficient in 1/m, range [0, 1]. Higher values build up fog faster with distance. Default 0.05 matches io.github.sceneview.node.FogNode's default.

start

Distance in metres at which fog begins to accumulate. Real surfaces closer than this stay crisp. Default 0.

end

Distance in metres at which fog is fully opaque. Default 30.

color

Fog colour. Default light grey-blue (0xFFCCDDFF) — matches io.github.sceneview.node.FogNode's default.

enabled

Whether fog is active. Default true.
