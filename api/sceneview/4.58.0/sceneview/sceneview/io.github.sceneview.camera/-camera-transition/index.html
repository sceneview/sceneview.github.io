CameraTransition

data class CameraTransition(val from: CameraShot, val to: CameraShot, val durationSeconds: Float, val easing: (Float) -> Float = CameraEasing.Expressive, val flyOver: Float = DEFAULT_FLY_OVER)

One camera move, from a shot to another over a duration.

Between two shots of the same subject the camera travels the arc around it. Between two subjects — another room, another object — it also flies over: it pulls back by flyOver times the distance between the two targets at mid-flight and comes back down, the way a navigation app zooms out to show the way before it lands, so the move never cuts through walls and the eye can see where it is going. Set flyOver to 0 for a straight carry.

val move = CameraTransition(from = current, to = plan, durationSeconds = 0.7f)
cameraNode.transform = move.shotAt(seconds).transform()
