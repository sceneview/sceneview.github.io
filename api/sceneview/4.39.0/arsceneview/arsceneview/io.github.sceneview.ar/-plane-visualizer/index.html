PlaneVisualizer

class PlaneVisualizer(engine: Engine, scene: Scene, plane: Plane) : TransformProvider

Renders a single ARCore Plane using native Filament geometry — V1 implementation.

V1 is the default plane visualizer again as of v4.16.1 (see #2203). v4.16.0 briefly shipped V2 (PlaneVisualizerV2) as the default but its visual output did not match the design intent under on-device QA, so the default was reverted while V2 is polished.
