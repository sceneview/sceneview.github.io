PlaneRendererBase

sealed interface PlaneRendererBase

Shared contract for SceneView's ARCore plane renderers.

SceneView ships two implementations of detected-plane visualization, selectable via ARSceneView's planeRendererVersion parameter:

  • PlaneRenderer — the default renderer (V1) again as of v4.16.1. Draws each detected plane as a flat polygon textured with a procedural soft grid. Battle-tested.

  • PlaneRendererV2 — experimental opt-in. v4.16.0 briefly shipped V2 as the default (depth-driven PBR mesh + HDR reflection + type-aware shading + scan-in) but on-device QA showed the visual output not matching the design intent, so the default was reverted in v4.16.1 while V2 is polished. The code remains in place so early adopters can opt in (Version.V2) and help shape the redesign — see #2203.
