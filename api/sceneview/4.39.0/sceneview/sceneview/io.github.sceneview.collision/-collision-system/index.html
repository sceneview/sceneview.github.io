CollisionSystem

class CollisionSystem(var view: View)

Manages hit-testing and collision queries against all registered Colliders in a scene.

Each Node with a collision shape registers a Collider here. The system supports ray-based hit testing from screen coordinates, normalized view coordinates, or arbitrary rays, as well as shape-vs-shape intersection queries.

Parameters

view

The Filament View whose camera projection is used for screen-to-ray conversion.
