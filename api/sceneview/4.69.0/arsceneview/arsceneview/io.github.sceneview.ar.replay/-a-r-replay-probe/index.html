ARReplayProbe

class ARReplayProbe(val playbackDataset: File?, var hideModels: Boolean = false) : ARSessionProbe

Ready-made ARSessionProbe for a replay QA run: provide it through LocalARSessionProbe and every ARSceneView below replays playbackDataset while this records what a test needs to grade the run — read observe from the test thread at any time.

  • frames replayed, and the frame at which the first plane tracked;

  • anchors currently tracking;

  • the screen share the visible ModelNodes' world bounds project to, and whether the camera sits inside one of them (a model scaled far too large).

Brightness is not measured here: it needs the screen's pixels, which the test reads from a screenshot and feeds to ARReplayMetrics.meanLuminance — see ARReplayObservation.

hideModels hides every model on each frame: the deliberate failure that proves the coverage check fails when nothing is drawn.
