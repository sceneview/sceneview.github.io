Aabb

data class Aabb(val center: Position = Position(0f, 0f, 0f), val halfExtent: Position = Position(0f, 0f, 0f))

An axis-aligned bounding box expressed as a centre / half-extent pair, mirroring Filament's Box convention. Used by the auto-centring pass to union the bounds of every renderable in the scene without touching Filament's mutable Box type — keeping the union math pure and testable.

val diagonal: Float

Length of the box's space diagonal — sqrt(x² + y² + z²) of extents. 0 for an empty box. This single scalar is what FramingGate tracks frame-to-frame to detect an async model landing and growing the scene's union bounds.
