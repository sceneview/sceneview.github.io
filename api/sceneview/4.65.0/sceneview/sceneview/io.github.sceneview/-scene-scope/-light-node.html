LightNode

@Composable
fun LightNode(type: LightManager.Type, intensity: Float? = null, direction: Direction? = null, position: Position = Position(x = 0f), color: Color? = null, apply: LightManager.Builder.() -> Unit = {}, nodeApply: LightNode.() -> Unit = {}, content: @Composable NodeScope.() -> Unit? = null)

A light source node (directional, point, spot, or sun).

At least one light must be added to the scene to see anything unless using unlit materials.

Simplified overload — pass common properties directly without needing apply lambdas:

LightNode(
    type = LightManager.Type.DIRECTIONAL,
    intensity = 100_000f,
    color = Color(1f, 0.95f, 0.9f),
    direction = Direction(0f, -1f, 0f),
    position = Position(0f, 5f, 0f)
)

Advanced overload — use apply for full LightManager.Builder access:

LightNode(
    type = LightManager.Type.SPOT,
    apply = {
        intensity(50_000f)
        falloff(10f)
        spotLightCone(innerAngle = 0.1f, outerAngle = 0.5f)
    }
)

Parameters

type

The LightManager.Type of light (DIRECTIONAL, POINT, SPOT, SUN, etc.).

intensity

Luminous intensity in candela (point/spot) or lux (directional/sun).

direction

Direction vector for directional/spot/sun lights.

position

World-space position of the light node.

color

Linear RGB light colour (defaults to white when null).

apply

Builder configuration for LightManager.Builder — for advanced properties (falloff, spotLightCone, sunAngularRadius, etc.).

nodeApply

Additional imperative configuration on the LightNodeImpl after creation.

content

Optional child nodes declared in a NodeScope.
