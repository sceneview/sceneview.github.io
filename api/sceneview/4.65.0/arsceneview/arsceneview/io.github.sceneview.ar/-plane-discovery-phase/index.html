PlaneDiscoveryPhase

enum PlaneDiscoveryPhase : Enum<PlaneDiscoveryPhase>

The observable phases of the PlaneDiscoveryGuide onboarding state machine.

Phase is a pure function of (cameraReady, isTracking, anyPlaneTracked, trackingFailureReason, elapsed time) — see PlaneDiscoveryGuideState.update.
