arsceneview/io.github.sceneview.ar.node/SceneMeshNode/SceneMeshNode

SceneMeshNode

constructor(engine: Engine, streetscapeGeometry: StreetscapeGeometry, meshMaterialInstance: MaterialInstance? = null, onTrackingStateChanged: (TrackingState) -> Unit? = null, onUpdated: (StreetscapeGeometry) -> Unit? = null, onClassifiedFace: (faceIndex: Int, classification: MeshClassification) -> Unit? = null, builder: RenderableManager.Builder.() -> Unit = {})

Parameters

engine

Filament engine.

streetscapeGeometry

The StreetscapeGeometry trackable to render.

meshMaterialInstance

Optional MaterialInstance painted on the mesh faces. When null, Filament's default material is used. For colour-coded overlays, pass a semi-transparent PBR or unlit instance.

onTrackingStateChanged

Called when streetscapeGeometry's TrackingState changes.

onUpdated

Called each ARCore frame while the geometry is tracked.

onClassifiedFace

Called once per triangle face when the node is first built (not on every frame). Receives the zero-based face index and the face's MeshClassification. On ARCore all faces of the same geometry share the same classification; on ARKit each face may have a distinct label.

builder

Optional hook into the underlying RenderableManager.Builder for shadow flags, layer masks, etc.
