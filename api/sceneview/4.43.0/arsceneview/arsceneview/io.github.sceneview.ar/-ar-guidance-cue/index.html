ArGuidanceCue

enum ArGuidanceCue : Enum<ArGuidanceCue>

What the AR coaching overlay is telling the user right now — one animated glyph per cue, the same vocabulary as Apple's ARCoachingOverlayView (surface onboarding, "move more", relocalization) and as ARGuidanceCue in SceneViewSwift.

NONE means nothing to say: the placement is fine, or a card (no surface, recovery failed, camera error) is already explaining the state. Hide your own chrome while the cue is anything else — see ArGuidanceState.isCoaching.
