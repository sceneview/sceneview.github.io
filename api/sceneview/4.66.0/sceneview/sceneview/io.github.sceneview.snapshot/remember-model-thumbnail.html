rememberModelThumbnail

@Composable
fun rememberModelThumbnail(snapshot: ModelSnapshot, fileLocation: String, size: Dp, options: ModelSnapshotOptions = ModelSnapshotOptions()): ModelThumbnailState

The thumbnail of the model at fileLocation, size wide and high, rendered by snapshot.

ModelThumbnailState.Loading until its turn has come and gone (draw a placeholder meanwhile), then ModelThumbnailState.Ready with the image on a transparent background, or ModelThumbnailState.Failed with the reason (see "What fails" on ModelSnapshot). A change of fileLocation, size or options starts again from Loading — or from the cached image — never from the previous model's image. Rendered once per file, size and options while the snapshot's cache holds it; a cell that leaves the composition before its turn is never rendered.

val engine = rememberEngine()
val snapshot = rememberModelSnapshot(engine)
LazyVerticalGrid(columns = GridCells.Adaptive(96.dp)) {
    items(models) { path ->
        when (val thumbnail = rememberModelThumbnail(snapshot, path, size = 96.dp)) {
            is ModelThumbnailState.Ready -> Image(thumbnail.bitmap, contentDescription = path)
            is ModelThumbnailState.Failed -> Icon(Icons.Default.BrokenImage, contentDescription = null)
            ModelThumbnailState.Loading -> CircularProgressIndicator()
        }
    }
}
